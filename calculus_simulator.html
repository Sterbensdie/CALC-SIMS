PANDUAN INPUT

Ikuti format pengisian berikut untuk mencegah System Error:

  • Gunakan Titik (.) untuk angka desimal, bukan koma.
    Contoh: 2.5
  • Waktu Akhir (t₁) wajib lebih besar dari Waktu Awal (t₀).

Bagi Mode FUNGSI CUSTOM:

Masukkan fungsi terhadap waktu t. Gunakan operator matematika standar:

  • Perkalian: gunakan bintang *
    (contoh: 2*t)
  • Pembagian: gunakan garis miring /
    (contoh: t/2)
  • Pangkat: gunakan simbol topi ^
    (contoh: t^2 untuk t kuadrat)
  • Penjumlahan/Pengurangan: + dan -
    (contoh: 3*t^2 - 2*t + 5)
